# Articulate!

A phone-friendly companion / full digital version of the party game **Articulate!**

- 6 categories, ~630 non-repeating cards each
- 30-second timed turns with buzzer-beaters, pause, and foul/discard
- Teams, live scoreboard, random category spinner, first-to-20/30/40
- "All-play" finish with confetti
- A no-scoring "Just cards" practice mode (timed or no-timer) + standalone all-play
- Add your own words (with duplicate checking)

Single self-contained `index.html` — no build, no server, works offline once loaded.
